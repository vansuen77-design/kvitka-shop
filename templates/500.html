{% load i18n %} {% comment %} The "server error" page. Deliberately no inheritance from base.html and no links to external stylesheets. The reason: a 500 is shown when something has already broken, and Django renders it WITHOUT context — no shop, no cart, nothing the header and footer take for granted. Inheritance would give a half-empty page, and a css link — a second request that may fail right after. So the page is self-contained: markup and styles inside, nothing is loaded from outside. It must always show. {% endcomment %}
