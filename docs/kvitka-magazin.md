# КВІТКА — документ магазина

Магазин цветов с доставкой, собран 16.09.2026 по шаблону АМИГО v3 (`CLAUDE.md`).
Эталон для форка: **АМИГО** (`OneDrive\Desktop\amigo-shop-КОПИЯ`, опт белья) — единственный,
который был на компьютере в начале сборки. Розничная часть — корзина, заказ с доставкой,
`normalize_quantity`, варианты, `makelocales` и набор тестов — написана по справочнику v2.
`miska-shop` (`PycharmProjects\miska-shop`) появился уже под конец; после этого магазин
сверен с ним и доведён до паритета — см. «Сверка с miska-shop» ниже.

Главный документ проекта — `CLAUDE.md`; этот файл дополняет его решениями и историей сборки.

## Что адаптировано

- **Справочники**: 13 бельевых заменены на 5 цветочных (`Kind`, `Flower`, `Occasion`, `Color`, `Size`).
  Состав букета, число цветков и высота — текст и числа, не фасеты (инвариант 1).
- **Товар**: убраны упаковка, минимальная партия, вес, размерный ряд; добавлены `family`, `stems`,
  `height_cm`, `composition(_uk)`, `summary_uk`.
- **Заявка → заказ**: `orders/draft.py` → `orders/cart.py` (`Cart`, `CartTotals` с порогом бесплатной доставки),
  `Request` → `Order` с полями доставки, `OrderLine` копирует артикул/название/цену (инвариант 5).
  Удалено «добавить списком» (оптовая функция). Адреса `/zakaz/` → `/korzina/`.
- **Без JavaScript**: плитка и страница товара — обычные формы на `orders:form-add`; строки корзины —
  формы на `orders:form-update` (кнопки «Обновить»/«Убрать»); JS только перехватывает (инвариант 14).
- **Панель подбора**: разнородный каталог — пустые значения скрыты (кроме выбранных), пустые группы не показываются.
- **Поиск**: регистронезависимо для кириллицы (варианты регистра + `name_uk`, состав, цветы) — грабля 19.
- **Сортировка**: добавлена «сначала популярные» (по `position`) как умолчание.
- **Двуязычность**: новая команда `makelocales` (`core/i18n_tools.py`) — сбор строк из шаблонов и кода без
  gettext, `--check` для проверки; подписи для базы (`FacetGroup.name_uk`) `seed_facets` берёт из `.po`
  (инвариант 10, грабля 22). Строки в словарях форм и `choices` помечены `gettext_noop`.
- **Демо-каталог**: 15 букетов с картинками-заглушками, которые рисует Pillow (`catalog/placeholders.py`);
  все названия и справочники сразу на двух языках.
- **Кабинет**: анкета — телефон и адрес доставки вместо компании и города; подставляются в заказ.
- **Админка**: заказы с блоком доставки, дашборд `kvitka_stats`/`recent_orders`; заголовки из `SHOP["NAME"]`.
- **Бот**: команды по заказам, новая `/segodnya` — что везём сегодня; остатки без упаковок.
- **Батники**: `ЗАПУСТИТЬ-КОПИЮ.bat` только проверяет миграции (инвариант 23) и зовёт `seed_facets`;
  новые `служебные\ПРОГНАТЬ-ТЕСТЫ.bat` и `ЗАПОЛНИТЬ-ДЕМО.bat`.
- **Палитра и знак**: розово-малиновый акцент, цветок вместо буквы «А» (`static/img/*`, og-image).

## Что исправлено относительно эталона

1. **`accounts/admin.py` перекрывал `SingleAdminUserAdmin`** из `core/admin.py`: приложение `accounts`
   регистрируется позже и подменяло защиту «последнего администратора нельзя удалить» обычным `UserAdmin`.
   Здесь `UserAdmin` наследуется от `SingleAdminUserAdmin`. **Предложение: перенести в АМИГО.**
2. JSON-ответ каталога не имел `Cache-Control: no-store` и `Vary: X-Requested-With` без `NoCacheMiddleware`
   (то есть в боевом режиме) — инвариант 13, грабля 18. Теперь их ставит `AjaxTemplateMixin`.
3. `TIME_ZONE = "Europe/Kiev"` → `"Europe/Kyiv"` (грабля 27).
4. Батник копии создавал миграции сам (`makemigrations`) — теперь только проверяет.
5. Русские строки без `{% trans %}` в крошках («Каталог») — обёрнуты.
6. Письмо восстановления пароля с именем магазина в шаблоне — имя передаётся через `extra_email_context`.
7. Страницы `seed_pages` не содержали `politika-konfidentsialnosti`, на которую ссылается форма, — добавлена.

## Сверка с miska-shop

Структура совпала (те же `orders/cart.py`, `core/i18n_tools.py`, `placeholders.py`, адреса
`/korzina/`). Из эталона перенесено то, чего не хватало:

- `Order.language` (миграция `orders.0002`) и **письмо покупателю «заказ принят»** на языке,
  на котором он оформлял заказ (`templates/orders/email_*.txt`, `notify._email_customer`);
  уходит в фоне вместе с Telegram. Пока `EMAIL_HOST` в `.env` пуст — печатается в журнал.
- `orders/services.py::create_order` — оформление вынесено из представления, строки пишутся
  одним `bulk_create` в транзакции.
- Команда `snapshot_db` (VACUUM INTO) — её зовёт `ОТПРАВИТЬ-НА-СЕРВЕР.bat` вместо однострочника.
- Тесты: дымовые (`test_smoke`), страницы админки (`test_admin_pages`), защиты `adopt_content`,
  `snapshot_db`, язык заказа, письмо покупателю.
- Попутно найдено дымовым тестом: несуществующий раздел `/katalog/net-takogo/` отдавал весь
  каталог со статусом 200 — теперь 404.

Не переносилось: `catalog/context_processors.menu` (меню у КВІТКИ строит `core.navigation`),
`accounts/signals.py` (анкета создаётся при первом заходе в кабинет), `СКИДКА-НА-КАТАЛОГ.bat`
(команда `set_discount` есть, батник — по желанию владельца).

## Что осталось владельцу

- Заменить демо-данные: `SHOP` в `config/settings.py` (название, телефон, адрес, часы, мессенджеры),
  `.env` по `.env.example` (домен, почта, Telegram), тексты страниц в админке, картинки-заглушки — своими фото.
- Проверить суммы в текстах страниц «Доставка и оплата» — они дублируют `SHOP` на момент сборки.
- Сервер: `deploy/УСТАНОВКА.md` (пользователь `kvitka`, юниты `kvitka*.service`), идентификатор туннеля
  Cloudflare вписать в `deploy/cloudflared.yml`.
- Первый запуск: `ЗАПУСТИТЬ-КОПИЮ.bat`, затем `служебные\ЗАПОЛНИТЬ-ДЕМО.bat` (если база пустая) и
  `служебные\ПРОГНАТЬ-ТЕСТЫ.bat`.
