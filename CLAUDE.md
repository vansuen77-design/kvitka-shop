## Инварианты [ядро] — НЕЛЬЗЯ нарушать

Нарушение любого пункта — ошибка, даже если тесты проходят.

**Данные**
1. Характеристики подбора — только ссылки на справочники, без свободного текста. Состав, описание, инструкция — текстовые поля, но не фасеты.
2. FK на справочник: `null=True, blank=True, on_delete=SET_NULL, related_name="products"`. M2M: `blank=True, related_name="products"` (без `null` — иначе `fields.W340`).
3. Скидка не хранится: есть, когда `old_price > price`; процент вычисляется; «−0 %» не показывать.
4. Количество нормализует **один** метод `Product.normalize_quantity()` (карточка, корзина, форма без JS, повтор заказа). Своя проверка количества где-то ещё запрещена.
5. Строки заказа копируют артикул, название и цену на момент заказа; `product` — `SET_NULL`.
6. Удаление справочника снимает товары с публикации (`pre_delete`), а не стирает.
7. Slug, по которому код что-то ищет (например `novinka`), задаётся явно в `seed_*`.

**Язык**
8. Русский текст в коде и шаблонах — ключ перевода. Каждая строка витрины — в `{% trans %}` / `_()`.
9. В шаблонах только `obj.title`, никогда `obj.name`. `Product.title` всегда украинский.
10. Никаких словарей перевода в коде: подписи для базы берутся из `.po` через `translation.override("uk")`.
11. После новых строк: `makelocales` → перевести пустые `msgstr` → `compilelocales`. `makelocales --check` проходит.

**Устройство**
12. Порядок middleware — строго как ниже. Процессоры, читающие сессию, проверяют `hasattr(request, "session")`.
13. Один адрес каталога отдаёт HTML или JSON: у JSON `Cache-Control: no-store`, у обоих `Vary: X-Requested-With`.
14. Каталог работает без JavaScript. JS только подменяет результаты и откатывается к обычной форме.
15. В JS поля формы — через `form.elements["имя"]`; поля не называть `action`, `method`, `submit`, `target`, `elements`.
16. Любое деление в аннотации SQLite — через `Cast(..., FloatField())`.
17. Порядок значений справочника в подборе — по `Meta.ordering` модели.
18. Блок, обещающий «в наличии», фильтрует по остатку и `status.is_orderable`.

**Защита**
19. Секреты только в `.env`: не в коде, архивах, чате, скриншотах. **Никогда не выводи содержимое `.env`**; проверка ключей: `grep -o '^[A-Z_]*=' .env`.
20. Админка: IP-фильтр + одноразовый код из Telegram; отказ — наша 404.
21. Любой `next` проверяется `url_has_allowed_host_and_scheme`.
22. Чужие заказы и чужая страница «спасибо» недоступны.

**Процесс**
23. Миграции создаёт только разработчик и кладёт в код. Батник владельца их только проверяет (`makemigrations --check --dry-run`).
24. Код едет с компьютера на сервер, содержимое — с сервера на компьютер.
25. Зависимости — только `Django`, `Pillow`, `waitress`, `whitenoise`. Новая — **только с явного согласия владельца**.
26. Тесты не содержат констант магазина: пороги, названия, цены — из `settings` или фабрик.
27. Имя магазина в новом коде — из `settings.SHOP["NAME"]`.

**Порядок middleware:**
```python
MIDDLEWARE = [
    "django.middleware.security.SecurityMiddleware",
    "whitenoise.middleware.WhiteNoiseMiddleware",
    "django.contrib.sessions.middleware.SessionMiddleware",
    "core.middleware.AdminAccessMiddleware",      # после сессий

    "core.middleware.AdminLanguageMiddleware",    # после Locale
    "django.middleware.common.CommonMiddleware",
    "django.middleware.csrf.CsrfViewMiddleware",
    "django.contrib.auth.middleware.AuthenticationMiddleware",

    "django.middleware.clickjacking.XFrameOptionsMiddleware",
```

## Точки расширения

### Новая характеристика подбора [ядро]
1. Модель-наследник `AttributeModel` (имя, `name_uk`, slug, активность, порядок).
2. Поле у `Product`: FK (`null=True, SET_NULL, related_name="products"`) или M2M.
3. Строка в `FACETS`: `FacetSpec(code, field, Model, _("Подпись"), multiple=?, in_tile=?, position=?)`.
4. `managers.RELATED` (FK) или `prefetch_related` (M2M).
5. `admin.py`: поле в `fieldsets` и `list_filter` (сами не появятся); по желанию — в `ProductQuerySet.search`.
6. Миграция → `makelocales` → перевод подписи → `compilelocales` → `seed_facets`.
   **Порядок важен:** `seed_facets` до перевода оставит `name_uk` пустым (грабля 22).

Результат появится сам: панель подбора, `?code=slug`, таблица на карточке, колонка прайса, снятие с публикации.

### Варианты одной модели [бизнес]
Вариант — отдельный товар со своим артикулом, ценой, остатком. Связь — строковое поле `family`.
`Product.variants()` — товары той же `family` (порядок по смыслу: граммы, память…). `variant_label` — подпись переключателя.

### Справочник с числом и цена за единицу [ядро]
Пример МИСКА: `PackSize.grams` (для наборов — общий вес «12 × 85 г = 1020»).
- `Product.price_per_kg` — Decimal, округление до гривны; нет фасовки → `None`, не 0;
- строка «Ціна за кг» в характеристиках, колонка прайса, подпись в плитке и переключателе;
- сортировка «дешевше за кг»: `Cast(price)*1000 / Cast(pack__grams)`, `nulls_last=True`;
- `Meta.ordering = ("grams", "position")`.

### Панель подбора [бизнес]
Опт с однородным каталогом — показывать значения с нулём. Разнородный каталог — скрывать нули (кроме выбранных) и пустые группы.

### Повтор заказа
POST из карточки заказа в кабинете. Позиции ищутся **по артикулу**, количество — через `Cart.add` → `normalize_quantity`,
недоступное перечисляется в сообщении. Добавилось хоть что-то → редирект в корзину, иначе обратно. Чужой заказ → 404, GET → 405.
Эталон: МИСКА, `accounts/views.py:order_repeat`.

### Опт (упаковки, заявка)
Эталон — АМИГО (v2 §1–§8): округление вверх до упаковки, минимальная сумма заявки, добавление списком артикулов.

## Грабли (симптом → правило)

| # | Симптом | Правило |
|---|---|---|
| 1 | Вместо 404 от админки — 500 | Проверки админки после `SessionMiddleware`; `hasattr(request, "session")` |
| 2 | «Со скидкой» = сортировка по цене | Деление в SQLite через `Cast` к float |
| 3 | Сортировка «теряет» раздел | `action` формы = адрес раздела; `replaceState` берёт путь из `form.action` |
| 4 | Ошибка всплывает, когда заполнили SMTP | После автозамен перечитывать f-строки |
| 5 | Сайт падает из-за `urls.py` | В middleware сначала дешёвая проверка пути, `reverse` — в `try` |
| 6 | На украинской версии русские названия | Только `.title` в шаблонах |
| 7 | Русский браузер → русский сайт | `DefaultLanguageMiddleware` до `LocaleMiddleware` |
| 8 | Деплой: «базы на разной структуре» | Локальный `migrate` в батнике отправки до снимка базы |
| 9 | Батник ломается на путях и `^` | Правила cmd из v2 §18.9 |
